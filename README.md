# LandRecord

**LandRecord** is an independent Indian land-record and land-services information platform.

It helps users understand land records, maps, documents, procedures, calculators, revenue services and related information in simple Hindi + English, while directing users to appropriate official sources.

> **Important:** LandRecord is not a government website and must never imply government affiliation or endorsement.

## 🔒 Master project rules

- **Mobile-first, but never hide all important options behind a hamburger-only navigation.**
- Hindi + English are first-class throughout the platform.
- Every public page uses the same header, footer, language controls and theme system.
- Every relevant page provides useful map/location context.
- Rule Engine / Smart Land Assistant is a core platform capability.
- Service pages should contain useful SEO content, official sources, internal links, tools and related services.
- No keyword stuffing, doorway pages or mass-produced thin content.
- State-specific rules must never be presented as India-wide rules.
- Government links must use authoritative sources where available.
- Never fabricate land ownership, cadastral boundaries, survey numbers, fees, legal outcomes or government records.
- APIs and Supabase are used only where legitimate and useful.
- Secrets never go into Git.
- Performance, accessibility and mobile UX are mandatory.
- GSC/indexing remains controlled until launch.
- Quality and usefulness scale before URL count.

## 🗺️ Maps

Maps are a core feature. Never present fabricated parcel/ownership/cadastral data as real. Official map portals such as state Bhu-Naksha services should be clearly identified as official external sources.

## 🧠 Rule Engine

The Rule Engine will guide users from their situation to the relevant record/service, documents, process, official portal and tools. Rules must be explainable and jurisdiction-aware. It must never be represented as a government decision.
